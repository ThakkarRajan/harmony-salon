## 📌 **STEP 1: Deploy Your Website (Choose One Method)**

### **Option A: Vercel (RECOMMENDED - Easiest!)**

#### **Why Vercel:**
- ✅ FREE hosting forever
- ✅ Works perfectly with Next.js
- ✅ Automatic SSL (HTTPS)
- ✅ Takes 5 minutes to deploy
- ✅ Free custom domain (harmonysalon.biz)

#### **Simple Deployment:**

1. **Create Vercel Account**
   ```
   👉 Go to: https://vercel.com/signup
   👉 Sign up with email or GitHub
   ```

2. **Deploy Your Site**
   
   **Method 1: Using Vercel CLI (Command Line)**
   ```bash
   # Install Vercel
   npm install -g vercel
   
   # Deploy
   cd "c:\Harmony Salon\harmony-salon"
   vercel
   ```
   
   **Method 2: Using Vercel Website (Drag & Drop)**
   ```
   1. Build your site first:
      npm run build
   
   2. Go to: https://vercel.com/new
   3. Drag the entire "harmony-salon" folder
   4. Click "Deploy"
   5. Done! ✅
   ```

3. **Add Your Custom Domain (harmonysalon.biz)**
   ```
   1. In Vercel dashboard, click your project
   2. Go to "Settings" → "Domains"
   3. Add "harmonysalon.biz"
   4. You'll get DNS instructions
   5. Add the DNS records to your domain registrar
   6. Wait 24-48 hours
   7. Your site is live at harmonysalon.biz! 🎉
   ```

## 🔍 **STEP 2: Add to Google Search Console**

This tells Google your website exists!

### **Instructions:**

1. **Go to Google Search Console**
   ```
   👉 https://search.google.com/search-console
   ```

2. **Add Your Website**
   - Click "Add Property"
   - Choose "URL prefix"
   - Enter: `https://harmonysalon.biz`
   - Click "Continue"

3. **Verify Ownership** (Easiest Method)
   
   **HTML File Method:**
   ```
   1. Google gives you a file like: google1234567890.html
   2. Download it
   3. Put it in your "public" folder
   4. Re-deploy (vercel or npm run build)
   5. Click "Verify" in Google
   ```

   **OR DNS Method:**
   ```
   1. Google gives you a TXT record
   2. Add to your domain's DNS settings
   3. Click "Verify"
   ```

4. **Submit Your Sitemap**
   ```
   1. After verification, click "Sitemaps" (left menu)
   2. Add: sitemap.xml
   3. Click "Submit"
   4. ✅ Google will crawl all your pages!
   ```

5. **Request Immediate Indexing**
   ```
   1. Click "URL Inspection" (top bar)
   2. Enter: https://harmonysalon.biz/
   3. Click "Request Indexing"
   4. Repeat for important pages:
      - /bridal
      - /contact
      - /reviews
      - /portfolio
   ```
